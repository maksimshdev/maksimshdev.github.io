Короткий ответ

Изи Пизи Инглиш — это…

мобильное приложение для русскоязычных пользователей, которые хотят запоминать английские слова и живые фразы с помощью карточек и интервальных повторений FSRS.

Как проходит занятие

  1. Пользователь выбирает тему, готовую колоду или собственные карточки.
  2. Сначала пытается вспомнить ответ, затем открывает перевод.
  3. Оценивает воспоминание одним из четырёх вариантов.
  4. FSRS рассчитывает, когда эту карточку полезно показать снова.

Это создаёт личную очередь повторений на сегодня вместо необходимости вручную управлять календарём каждой карточки.

Чего приложение не обещает

Изи Пизи Инглиш — тренажёр лексики. Оно не заявляет, что само по себе заменяет преподавателя, полноценный языковой курс, грамматическую программу или разговорную практику с людьми.
