Почему тематическая группировка помогает

Один глагол с частицей может иметь несколько значений. Алфавитный список ставит похожие формы рядом, но не объясняет, где они пригодятся. Тематическая колода создаёт контекст: фразы из одной сессии относятся к общей ситуации, и значение легче отличить от соседнего.

Цель раздела — не «закрыть все фразовые глаголы», а сделать конкретные значения доступными для узнавания и собственной речи.

Как проходить колоды

  1. Выберите одну ситуацию, которая сейчас вам нужна.
  2. Сначала тренируйте понимание EN → RU.
  3. Добавьте RU → EN, чтобы учиться самостоятельно вспоминать выражение.
  4. Оценивайте карточку по фактическому качеству ответа.
  5. Для сложного значения добавьте собственный пример или уточните перевод.
